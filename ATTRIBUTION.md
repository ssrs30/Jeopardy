## Font

`Pix32.ttf` is **not included** in this repository because the author forbids redistributing the font file.

- Source: [Pix32 on dafont](https://www.dafont.com/pix32.font) / [JobYu/Pix32](https://github.com/JobYu/Pix32)
- Personal and education use is typically free; commercial use needs a paid license
- Optional: download `Pix32.ttf` yourself and place it in the project root or the `UI/` folder
- If the file is missing, the game falls back to the default pygame font

## Questions

Bundled questions in `offline_questions.py` are original short trivia written for this project.
Optional LLM questions are generated at runtime by the user's own API key.
